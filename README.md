# Language Translation Tool

## Project Overview
A Python-based language translation application that allows users to translate text into different languages through a simple web interface.

## Technologies Used
- Python
- Streamlit
- Translate library

## Features
- Simple user interface
- Multiple target languages
- Text input and translation output
- Error handling

## How It Works
1. The user enters text.
2. The user selects a target language.
3. The application sends the text to the translation service.
4. The translated result is displayed.

## Installation
Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
streamlit run app.py
```
